# BLINDSPOT · 1:1 FPS

브라우저에서 플레이하는 3D FPS 프로토타입입니다. Node.js 24+와 최신 데스크톱 Chrome/Edge/Firefox가 필요합니다. 모바일 터치 조작은 지원하지 않습니다.

## 실행

```sh
npm ci
npm start
```

기본 포트는 3000이며 `PORT=8080 npm start`로 변경할 수 있습니다. 한 명이 **새로운 방 만들기**를 누른 뒤, 다른 한 명이 같은 서버 주소에서 6자리 방 코드를 입력합니다. 화면의 **전투 시작**을 누르면 마우스가 잠기고 1인칭 조작이 시작됩니다. 방에는 최대 두 명까지 접속할 수 있습니다.

서로 다른 네트워크의 친구와 플레이하려면 이 Node 서버를 WebSocket을 지원하는 호스팅에 배포하고 동일한 HTTPS 주소로 접속해야 합니다. 같은 LAN에서는 호스트의 LAN IP와 포트로 접속할 수 있습니다. 서버는 `0.0.0.0`에 바인딩합니다. 현재 저장소만으로 공개 접속 주소가 생성되지는 않습니다.

## 조작 및 규칙

- 마우스: 시야 / 왼쪽 클릭: 발사. 기관단총·소총은 누르고 있으면 자동 발사.
- WASD: 무음 걷기 / Shift: 달리기와 발소리 / Space: 점프.
- R: 1.6초 재장전 / B: 무기고 / Esc: 마우스 잠금 해제.
- 체력 100, 머리는 기본 피해의 2배. 사망하면 3초 뒤 부활하고 상대에게 1점이 추가됩니다. 시간·점수 제한 없이 연습할 수 있습니다.
- 권총 2종, 샷건 2종, 기관단총 1종, 소총 3종, 저격소총 2종. 무기고에서 피해·반동·무게·속도·탄창을 비교할 수 있습니다.
- 한 발의 기본 피해는 10–20입니다. 샷건은 한 발의 피해를 4–5개 펠릿에 나누며, 전부 맞히면 표시된 기본 피해가 들어갑니다. 머리에 맞은 펠릿만 피해가 2배가 됩니다.
- 무게에 따라 걷기 속도는 `4.6 - 무게 × 0.28` m/s, 달리기는 그 속도의 1.65배입니다. 무기 교체에는 1.2초 준비 시간이 필요합니다.
- 상대 위치 표시·미니맵·벽 너머 윤곽선이 없습니다. 엄폐물 뒤의 상대는 보이지 않으며 총알도 막힙니다. 발소리와 총성은 거리에 따라 작아집니다.

## 검증

```sh
npm test
# 브라우저 검증 (Chromium 설치 필요)
npx playwright install chromium
npx playwright test
# 이 클라우드 환경의 기존 Chromium 사용:
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
```

Node 통합 테스트는 실제 서버와 WebSocket 클라이언트를 사용합니다. 방 생성/참가/정원, 무음 걷기, 달리기 소리, 점프, 몸통/머리 피해, 발사 간격, 재장전, 사망/부활, 무기 교체를 검증합니다. 브라우저 테스트는 실제 WebGL 렌더링과 두 브라우저 접속 및 무기 선택을 확인합니다.

## 현재 범위

선택 가능한 세 맵, 기하학 캐릭터와 총기 모델, 합성 효과음으로 구성된 초기 프로토타입입니다. 서버가 이동 속도·피해·탄약을 계산하지만, 경쟁 서비스 수준의 안티치트·지연 보정·계정·매치메이킹·영구 점수는 아직 없습니다. 방과 점수는 서버 재시작 시 사라집니다. 저격소총도 요구한 피해 범위에 맞춰 기본 피해를 19와 20으로 설정했습니다.

## 친구와 인터넷으로 플레이하기 (Render)

GitHub Pages는 정적 파일만 제공하므로 이 게임의 방/전투 서버를 실행할 수 없습니다. **WebSocket을 지원하는 Node Web Service**가 필요합니다. 저장소에 `render.yaml`이 포함되어 있습니다.

1. https://render.com 에서 GitHub 계정으로 로그인합니다.
2. **New → Blueprint**에서 `dokko-dev/fps_prototype` 저장소를 연결합니다. 또는 **New → Web Service**로 연결하고 아래 값을 입력합니다.
3. Runtime: **Node**, Build Command: `npm ci --omit=dev`, Start Command: `npm start`, Health Check: `/health`. `NODE_VERSION`은 `24`로 설정합니다. Root Directory는 비워 둡니다. 포트는 Render의 `PORT`를 자동으로 사용합니다.
4. 요금제를 확인하고 생성/배포합니다. 무료 플랜은 사용 가능 여부와 정책에 따라 휴면·콜드 스타트가 있을 수 있습니다. 이 구성은 유료 플랜을 자동 신청하지 않습니다.
5. 배포 완료 후 Render가 표시하는 **https://…onrender.com** 주소를 두 사람 모두 엽니다. 한 명이 방을 만들고 다른 한 명이 같은 주소에서 방 코드를 입력합니다. 친구는 Node.js나 게임 설치가 필요 없습니다.

단일 인스턴스로 운영하세요. 방 정보는 메모리에 있어 여러 인스턴스에 분산되면 서로 만나지 못할 수 있습니다. 재배포·휴면·서버 재시작 시 방과 점수가 초기화됩니다. Render의 실제 배포는 계정에서 진행해야 하며, 저장소 파일만으로 공개 서버가 생성되지는 않습니다.

### Windows에서 최신 코드 적용

실행 중인 서버에서 Ctrl+C를 누른 뒤, `fps_prototype` 폴더에서:

```powershell
git pull origin main
npm.cmd ci
npm.cmd start
```

브라우저에서 Ctrl+F5로 새로 고침하세요.

## BRIDGE YARD 맵과 사격 확인

스페셜 솔져의 다리 전투 분위기에서 착안한 독자적인 맵입니다. 원본 맵의 정확한 복제는 아니며, 중앙 다리·운하·양쪽 진영·다리 기둥·엄폐물로 구성했습니다. 물 위로 걸어갈 수 없고 중앙 다리로 건너야 합니다.

혼자 방에 있어도 사격할 수 있습니다. 서버에서 탄약이 소비되면 짧은 노란 탄도(약 0.12초), 총구 섬광, 반동과 총성이 나옵니다. 탄도는 서버의 펠릿/피격/엄폐물 판정 지점에서 끝나고 벽 너머로 표시되지 않습니다. 상대도 공간 안에서 같은 탄도를 볼 수 있습니다. 재장전·무기 준비·탄약 부족으로 발사가 불가능하면 이유가 표시됩니다.


## 전술 업데이트: 조준·피격·이동·세 맵

- 방 생성 전에 전장을 선택합니다. 참가자는 방장의 맵으로 자동 입장합니다. **BRIDGE YARD**(다리), **GREEN RIDGE**(실제 높낮이가 있는 언덕), **DUST DEPOT**(경사 훈련장)입니다. 언덕과 경사는 화면 장식이 아니라 이동·피격 판정에도 반영됩니다.
- **우클릭을 누르는 동안 조준**합니다. 돌격소총은 도트 사이트, SR2는 4배, SR8은 6배 스코프를 사용합니다. 조준하면 이동 속도와 마우스 감도가 줄어듭니다. 우클릭을 놓거나 Esc를 누르면 해제됩니다.
- 총기마다 슬라이드·총열·탄창·개머리판·펌프·스코프 등을 다르게 구성했습니다. 실총 모델을 정확히 재현한 에셋은 아니며 총기 종류별 형태를 구분하는 자체 모델입니다.
- 이동 중에는 약 3.2도, 달리기는 약 5.7도, 공중에서는 추가 약 6.9도의 탄 퍼짐이 생깁니다. 조준해도 이동 페널티가 사라지지 않습니다. 샷건의 기본 펠릿 퍼짐은 별도로 더해집니다. 피해와 퍼짐은 서버에서 계산합니다.
- 피격 시 화면 가장자리가 붉게 물들고 약 0.7초 동안 사라집니다. 연속 피격 시 효과가 갱신됩니다.
- 내 이동은 60Hz 입력 예측과 서버 확인 후 미처리 입력 재적용을 사용합니다. 키를 놓으면 추가 감속 없이 멈추고, 상대 위치는 부드럽게 보간합니다. 키 해제·창 전환 입력도 즉시 전달합니다. 정적 그림자는 맵을 바꿀 때만 갱신하고 픽셀 비율을 제한해 렌더링 부담을 줄였습니다. 네트워크 지연이나 낮은 기기 성능 자체를 없애지는 못합니다.

| 종류 | 피해 감소 시작 → 최소 피해 거리 | 최소 피해 비율 |
| --- | --- | --- |
| 권총 | 8m → 28m | 35% |
| 샷건 | 7m → 23m | 25% |
| 기관단총 | 10m → 32m | 45% |
| 돌격소총 | 16m → 55m | 65% |
| 저격소총 | 감소 없음 | 100% |

중간 거리는 선형으로 감소합니다. 헤드샷은 감소된 피해에 2배를 적용합니다. 피해는 내부적으로 소수점으로 계산하고 체력 표시만 올림합니다. 이 수치는 실제 탄도 시뮬레이션이 아니라 100 체력에 맞춘 게임 밸런스입니다.
